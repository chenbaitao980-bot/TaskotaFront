父任务树选择器 — 交互模型改前/改后（第三轮增量）

改前（点即关闭）
打开审核卡点父任务按钮 → 底部弹层，根节点默认全展开
↓
点未选中节点Navigator.pop(node) → 选中并立即关闭弹层
↓
再点已选节点Navigator.pop(clearSelection) → 清空并立即关闭弹层
↓
缺点① 点一下就关，无法反复对比 ② 取消后想重选需重开 ③ 无一键展开/收起 ④ 根节点默认全展开
改后（点选不关闭 + 完成按钮）
打开弹层默认收缩；已选节点自动展开祖先路径（勾选可见）
↓
点节点仅切换内部 _selectedId 勾选（已选→取消勾选，未选→勾选），窗口保持打开
↓
一键展开/收起header unfold_more/less 按钮：全折叠→展开全部，否则收起全部
↓
底部「完成」Navigator.pop(node ?? clearSelection) → 有勾选返回节点 / 无勾选返回清空哨兵
↓
X / 点外Navigator.pop(null) → 关闭不保存，不误清父任务

审核页 _ParentTaskButton._openPicker 消费契约不变（null 忽略 / clearSelection 清空 / 节点选中）→ 审核页零改动。 契约：D1 默认收缩 / D2 切换勾选+完成 / D3 再点取消+完成清空 / D4 一键展开收起 / D5 X关闭null / D6 选中路径展开 / D7 无勾选完成→哨兵。
